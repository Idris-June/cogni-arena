# E-Invoicing Game Arena

A Kahoot-style quiz game for e-invoicing training.
The host runs the game and shares the presenter screen. Players join from their own phone or laptop and answer live.

| File | Who uses it |
|------|-------------|
| `cogni-players.html` | Players |
| `cogni-host.html` | The host only (locked with an admin code) |

---

## For players

1. Open **cogni-players.html** (the host will share the link).
2. Enter the 6-digit **Game PIN** shown on the presenter screen.
3. Enter your name. Please use the same name every day.
4. For team games, create a team (team name and teammates) or join an existing one.
5. Answer on your device before the timer runs out. Faster correct answers earn more points.
6. Watch the presenter screen for answers and the leaderboard.

**Tips**
- No app or sign-up needed. Works in Chrome, Edge or Safari.
- If you can't join on office Wi-Fi, try mobile data.
- If the page refreshes, enter the same PIN and name to rejoin. Your points stay.

---

## For the host

1. Open **cogni-host.html** and enter the admin code.
2. Pick the day's programme. A Game PIN is created.
3. Click **Open presenter screen** and share that window in your meeting.
4. Share the players link. Players join with the PIN.
5. Pick a game on the left, then use the big orange button to move through it (start, reveal, leaderboard, next).

**Tips**
- Keep the host tab open during the session. If it refreshes by mistake, sign in again and click **Resume it**.
- To change the admin code: sign in, click **Change admin code**, then upload the new `cogni-host.html` in place of the old one. The code needs at least 8 characters, with letters and numbers.
- Never share the admin code or the host link with players.
- Test once on the office network before the first session.

---

## Good to know

- Nothing is stored online. Each game lives only for that session.
- Rules are simplified for teaching. Check official dates and rules on [mof.gov.ae](https://mof.gov.ae).
